# Ocean Optics Color Reconstruction
A GUI I made to test conversions from a wavelength spectrum collected by an <a class="link" href="https://photos.labwrench.com/equipmentManuals/9443-3596.pdf">Ocean Optics USB2000 Spectrometer</a> to RGB values that can be displayed on a screen. The concept is that I would record my own screen with it and train a model to reconstruct the colors displayed, though to generalize this to colors not displayed by the screen, I need to either use existing CIEXYZ color matching functions on a calibrated spectrum or continue working on this to get my own data on human perception of colors. For now, it just has an option in the code of whether to use CIEXYZ conversion, or a trained model, and a model can be trained with recording_reader.py.
