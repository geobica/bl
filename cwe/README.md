This is a developmental version of the Clock with Everything, a clock/calendar which I intend to fill up with every timekeeping method I can think of.

Version v0.1 has a basic Zodiac Wheel, Lunar Phases, and Earth Rotation, as well as a 12-hour clock with hour, minute, and second hands.

The Zodiac Wheel and Lunar Phases are not perfectly aligned with astronomical reality, as for now they just use linear approximations.
